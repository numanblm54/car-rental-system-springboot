# User Stories

## US-01 — Start Rental

**As a** System User
**I want to** start a rental for a vehicle and customer
**So that** the rental process can begin.

---

## US-02 — End Rental

**As a** System User
**I want to** end an active rental
**So that** the rental process can be completed.

---

## US-03 — Add Customer

**As a** System User
**I want to** add a new customer to the system
**So that** the customer can rent a vehicle.

---

## US-04 — Add Car

**As a** System User
**I want to** add a new vehicle to the system
**So that** the vehicle can be used for rental operations.
